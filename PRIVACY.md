# Privacy policy

DevOps Nimbus Docker is a free learning project. This policy explains what personal data it
handles, written with India's Digital Personal Data Protection Act, 2023 (DPDP Act) in mind.
It is not legal advice.

## What we collect

**Nothing.** The learning site ([sandeepkomal.github.io/Docker](https://sandeepkomal.github.io/Docker/)) has no accounts, sign-up, forms, cookies, analytics, ads or
trackers, and loads nothing from other sites. Its security policy blocks it from sending data
anywhere.

- **Your progress** (levels, quiz scores, solved scenarios, score and activity days) is saved
  only in your own browser's storage. It never reaches us. The site's **Clear it** button erases
  it, and **Download my progress** creates a file that stays on your device.
- **Examples and sample data** in this repository and on the site are synthetic. They use
  reserved test domains and documented example values, never real people.

## Hosting and GitHub

The site is hosted on GitHub Pages and this repository on GitHub. GitHub may log visitors'
IP addresses for security and handles that data under the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
We do not receive or use those logs.

Anything you post on GitHub (issues, pull requests, comments, commits) is public and handled by
GitHub. Commit metadata includes the name and email you commit with; you can use GitHub's
private `noreply` address instead.

## Contributing without personal data

Never put real personal data in an issue, pull request, example, log or test: no Aadhaar, PAN,
phone numbers, personal emails, addresses, bank details, customer records or production data.
Use made-up values and reserved domains such as `example.com`.

## Children

The project collects no data from anyone, including people under 18. Learners of any age can
use the site without sharing personal data.

## Your requests

If personal data about you appears anywhere in this repository or its issues, or you have a
privacy question or complaint, contact [@SandeepKomal](https://github.com/SandeepKomal) on
GitHub. We will remove personal data that should not be here as soon as possible. Do not
include the personal data itself in a public issue.

## Changes

If the project ever starts collecting personal data, this policy will be updated first, and the
feature will provide notice, ask for consent where needed, and offer a way to withdraw it.
