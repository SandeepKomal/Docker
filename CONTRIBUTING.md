# Contributing

Contributions that make the Docker examples clearer, safer, and easier to reproduce are welcome.

Good contributions include corrected Docker guidance, practical Dockerfiles, Compose examples, networking/storage examples, troubleshooting improvements, CI/CD examples, and image-security practices.

Before opening a pull request:

1. Explain what changed and why.
2. Test commands or examples where practical.
3. Do not commit secrets or real environment files.
4. Keep examples focused and reproducible.
