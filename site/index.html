Practise on your own machine

Get Docker and the course

Docker Engine on Linux, or Docker Desktop. Both are free for learning.

# 1. Check Docker works
docker run --rm hello-world

# 2. Get the course
git clone https://github.com/SandeepKomal/Docker.git
cd Docker

# 3. Start with the security lab
cd docs/container-security-lab
docker build -f Dockerfile.baseline -t lab:baseline .

Clean up when you are done

Labs leave images and build cache behind. See what they use, then remove only what you no longer need.

docker system df
docker container prune
docker image prune
docker builder prune
